# 🚗 Приложение поиска и подбора автозапчастей (Favorit-parts API)

Клиентское веб-приложение на React + Redux для интеграции с внешним API-сервисом проценки автозапчастей ООО "ЮРАЛ" (Favorit-parts). 

Приложение реализует двухэтапный процесс подбора номенклатуры: от первичного поиска производителей по артикулу детали до получения итогового списка оригиналов и аналогов с фильтрацией и сортировкой по складам.

---

## 🛠 Стек технологий

- **Frontend:** React 19, Redux Toolkit, React-Redux
- **Сборщик:** Vite
- **Стилизация:** Bootstrap 5 (адаптивная вёрстка desktop / mobile)
- **Тестирование:** Vitest, React Testing Library, JSDOM
- **Backend / Proxy:** Vercel Serverless Functions (Node.js) для надежного скрытия API-ключа в Production
- **Конфигурация прокси:** Vite Proxy (`vite.config.js`) для локальной разработки / Vercel Serverless Function (`api/hs/hsprice.js`) для защиты API-ключа

---

## ✨ Ключевые возможности и UI/UX решения

1. **Двухэтапный подбор:**
   * **Этап 1:** Ввод артикула и получение списка доступных брендов/производителей.
   * **Этап 2:** Запрос предложений и аналогов по выбранному бренду (`analogues=on`).
2. **Оптимизация отображения складов:**
   * Группировка одинаковых позиций детали с разных складов в одну строку таблицы.
   * Автоматический выбор и акцентирование **самого дешевого склада** (минимальная цена).
   * Компактный выпадающий список (аккордеон) со скроллом для детального просмотра всех складов позиции.
3. **Фильтрация и адаптивность:**
   * Переключатель **«Скрыть (0 шт.)»** для отсеивания недоступных товаров.
   * Полноценная адаптация под мобильные устройства: превращение таблицы в компактные 2-уровневые карточки.
4. **Обработка состояний:**
   * Индикация загрузки (loading spinner) и информативные ошибки API.
   * Разделение введённого значения в инпуте и активного запроса (`activePartNumber`), предотвращающее рассинхрон заголовков при редактировании формы.

## 💻 Локальный запуск и разработка

### 1. Клонирование репозитория
```bash
git clone https://github.com/abelovdev/yural-app.git
cd yural-app
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск локального сервера разработки
```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.

## 🧪 Тестирование

Приложение покрыто Unit-тестами (Redux slice logic) и Integration-тестами компонентов (`SearchBar`, `OffersTable`).

* **Однократный прогон тестов (Single Run):**
```bash
npm run test
```
* **Запуск тестов в режиме отслеживания изменений (Watch Mode):**
```bash
npm run test:watch
```
